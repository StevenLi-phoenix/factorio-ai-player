Version: 0.5.1
Date: 2026-10-30
  Changes:
    - BREAKING: gather, deconstruct and build_ghosts no longer teleport to their
      targets. They act only on targets within character reach
      (can_reach_entity, build_distance for ghosts); otherwise they start a walk toward the nearest target
      and return a "walking ... retry next turn" result. build_ghosts no longer
      revives ghosts out of reach (ghost revive ignores character distance), and
      steps aside by walking when the character stands on a ghost.
    - pickup only collects ground items within reach.
---------------------------------------------------------------------------------------------------
Version: 0.5.0
Date: 2026-10-30
  Changes:
    - BREAKING: move, goto and return_home no longer teleport. They start a
      walk (scripts/movement.lua) that the character completes over the
      following ticks; the outcome (arrived / blocked / timeout) is appended to
      the next turn's action results. goto keeps its name and parameters.
      Prompts that assumed instant arrival must check the result next turn.
  Features:
    - AIMovement: asynchronous straight-line walking driven from on_tick
      (also while autonomy is disabled). No pathfinding; a blocked walk fails
      after ~45 ticks without progress instead of waiting for the timeout.

Version: 0.4.2
Date: 2026-08-29
  Features:
    - Remote interface: get_chat lets an external harness poll the mod's
      chat ring buffer directly (no python bridge needed).
    - Remote interface: import_blueprint stages a blueprint string as entity
      ghosts at a position (build_blueprint, falling back to manual

      to a blueprint string.

Version: 0.4.0
Date: 2026-07-16

    - Remote interface: query/list_queries expose a read-only query registry
